## 🇺🇸 English

### 📌 Overview
ALSSPORT is an online e-commerce platform designed for selling sports gear, athletic wear, and fitness accessories. It features a complete shopping flow, customer order management, and a comprehensive admin management panel.

### ✨ Key Features
- **Product Catalog:** Filter by category, price, and brand.
- **Admin Dashboard:** Manage products, orders, categories, and customer testimonials.
- **Shopping Cart & Checkout:** Streamlined order placement process.
- **Responsive Design:** Optimized for desktop and mobile displays.

### 🚀 How to Run Locally
1. **Clone the repository:**
   ``bash
   git clone https://github.com/hzn806512-source/ALSSPORT.git
Setup Database:
Create a MySQL database named alssport in phpMyAdmin.
Import the schema from /database/alssport.sql.
Database Configuration:
Update your database credentials in your DB connection file.
Launch:
Place project inside xampp/htdocs/ALSSPORT and navigate to http://localhost/ALSSPORT.
